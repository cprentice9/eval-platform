When does an LLM judge get it wrong?

Teams grade chatbot answers with another model because people are slow and expensive. This project checks that shortcut. It gives an LLM judge the same answer pairs that {{ judge_count|default:"65" }} people already judged on the MT-Bench benchmark, then measures where the judge and the people disagree.

How it works

  1. Run models on the 80 questions

    Each run saves every answer, what it cost, and a fingerprint of its settings so it can be repeated.

    Working now

  2. Have an LLM judge pick the better answer

    The judge sees the same pairs the people saw, without their votes, once in each order to catch a bias toward the first answer.

    {% if judged %}Working now{% else %}Next{% endif %}

  3. Measure where they disagree

    Agreement rate and Cohen's kappa, broken down by model and by question category.
